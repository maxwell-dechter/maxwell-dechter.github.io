This is my clicker game. Because Python console in CodeHS did not allow for any listeners to be used, I used the enter key for the user's click. Essentially, you click until you can afford an upgrade, which would make your clicking faster. You continue upgrading until you stop, so there is no win condidtion. In creating this project, I used collaboration and innovation. I made this project with my friend, each of us improving on each other's design and creating new features, using comments to explain our code to eachother. Innovation because getting around the listener problem was tough. Eventually though, we were able to create a system that prevented the user from cheating while also using keyboard inputs that could be held down to break the game. I learned how to collaborate effectively with teammates through this project, as well as getting around problems that inhibited progress.
