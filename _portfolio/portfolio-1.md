This is my copy of Asteroids. It plays just like the original game, just using CodeHS. You shoot asteroids and survive to gain score, you can move around with momentum to avoid asteroids, and even "hyperspace" to avoid danger. I coded it with Javascript, using my knowledge on how to use Geometry to my advantage. CodeHS only lets me move objects with the x and y axis, not directionally. So using sine and cosine, I calculated the x and y distance in a direction based on the hypotenuse. In coding this project, I learned how to manage velocity and direction in an environment that did not directly support them. I also learned how to use attributes to my advantage in order to determine what class an object would fit in, while not being able to assign classes. The greatest challenge that I solved while making this project was that of movement. It took a good bit of thinking to use the variables that I could control (direction and magnitude) to find the variables that I needed (x and y). After I figured this out, movement was easy.
