" collection: portfolio --- This is my copy of Five Nights at Freddy's. Essentially, it is a five minute period, where you have to survive against multiple enemies that will attack you throughout that time period. They all work on random numbers and if statements, in order to move to your office (your base). In your office, you are able to check the cameras, which reveals where all of the enemies are within the building (excluding the kitchen). You can also check if an enemy is in either of your doorways using the lights, and send them back using the doors. If you fail to send them away while they are in your doorway for too long, you lose. I used Javascript on CodeHS to code this, and the main skill I used was managing layers and collaboration. The game is essentially just three different screens, each on a different layer. The cameras, start screen, and office. Through this project, I learned how to incorporate constructive critiscm to better my work, as I recieved input from my peers on how to improve my project. Some even helped as we were working on it to make the game better. The main challenge that I solved with this project was how to get the enemies to show up on the cameras and in the halls. I solved it by creating a boolean that would remove the camera displays of the enemy if the cameras where not on, and vice versa for the office. Overall, I improved by debugging and complexity management skills.
